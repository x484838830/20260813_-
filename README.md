## 關於這場訓練

這場訓練帶大家實際做一次 **矽基抽樣（Silicon Sampling）**——把問卷受訪者的背景變數餵給語言模型，讓模型「扮演」那個人回答問題，再跟真人的實際答案比對，看模型模擬出來的母體像不像真的母體。

我們複製的是 Argyle et al. (2023) 發表於 *Political Analysis* 的〈Out of One, Many〉Study 2，用美國全國選舉研究（ANES）2020 年的資料，讓模型模擬「2020 年總統大選投給誰」。

原論文用 GPT-3，我們用 2026 年的 GPT-5.6——方法照抄、模型換代，看三年後的模型能不能重現三年前的結果。

## 怎麼開始

**路線 A｜用網頁版（不用寫程式）**
1. 打開上面的網址
2. 填入自己的 OpenAI API key
3. 照 1 到 6 的步驟走一遍，跑 100 到 300 人就足夠看出所有現象

**路線 B｜跑程式碼**
1. 下載 `20260813_教學程式碼.ipynb` 和 `anes2020_study2_frozen.csv`，放同一個資料夾
2. 安裝套件：`pip install pandas matplotlib openai openai-gabriel`
3. 在程式碼的 `os.environ["OPENAI_API_KEY"] = ""` 填入自己的 key
4. 從第一個區塊開始依序執行

需要 Python 3.10 以上。GABRIEL 是非同步函式，在 notebook 裡要用 `await` 呼叫。

**只有十分鐘**：翻教學手冊第一章（五分鐘看懂在做什麼），再打開網頁版的步驟 3 點幾個人看看 persona 長什麼樣。

## 今天會看到什麼結果

一句話：**像一張比例正確、但整體染了色、又被修圖修過頭的地圖。**

- **結構像**——哪個群體偏紅偏藍、什麼因素跟投票綁得緊，幾乎完美重現
- **位置不像**——整個模擬母體比真實母體藍了約 8 個百分點
- **紋理太乾淨**——跨黨投票、不按牌理出牌的人被抹平了

所以它**可以拿來比較**（A 組比 B 組更傾向什麼），但**不能拿來讀數**（任何百分比都不可直接引用）。細節在教學手冊第八、九章。
